API and feeds

The same records the site shows, as JSON and as feeds. Every response names the registers its rows come from and their licences (licence_summary); a credit a licence requires travels with the data. Reuse conditions lists them per source.

{{ m.section_heading("1.", "Feeds") }}

Free, with no key. Each feed holds the 50 most recently changed records. Any list filter works on a feed: {{ example_feed }} is new and changed data-centre proposals in Virginia. The proposal list and the map link their own feed under “View as”, and the opportunity list links one above its rows.
