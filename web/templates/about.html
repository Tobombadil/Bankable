About & sources

Infraqueue fuses public energy and infrastructure registers into one record per project. This is the public, delayed tier only: no login, no live data, no admin.

Infraqueue is a placeholder codename, not the permanent product name (docs/12-naming-shortlist.md). Every hostname and brand reference in this build is a stand-in.

Tiers

Public data is delayed {{ lag_days.supply }} days for proposals and {{ lag_days.opportunities }} days for opportunities from the date a source was retrieved -- public_at, computed and enforced by the API, governs what this site can show; nothing here filters further. A live, undelayed tier (Pro) and a bulk API are planned but not built on this site yet.

Method notes

  • Placement on the map follows source precision: an exact coordinate where the source supplies one and its licence allows raw publication; otherwise a county centroid (US Census Gazetteer 2024, public domain); records with neither a usable county nor a state are counted as Unplaced rather than guessed at.
  • Clustering on the map is computed server-side by GET /v1/proposals/geo (docs/23); this page's client script renders whatever the API returns and does not cluster on its own.
  • The default map and proposal list show active lifecycle states only (announced through under construction); withdrawn and cancelled proposals sit behind the "Include withdrawn & cancelled" toggle, because most of this dataset's history is withdrawn queue positions and a default view of them reads as a map of what died rather than what's active.
  • NESO TEC Register rows have no US-style county or state field in the source and are counted under Unplaced rather than guessed at.
  • The map's basemap tiles come from OpenStreetMap; a lightweight world-country and US-state outline layer (Natural Earth and US Census Bureau TIGERweb, both public domain) is drawn underneath them so the map stays legible if the tile provider is ever unreachable.
