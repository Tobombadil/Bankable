Reuse conditions

Every record here comes from a public source, and each source sets its own terms. This page lists, for each source we publish, its licence, the credit it requires and anything that passes to you if you reuse the data from this site, its API, feeds or exports.

This is a summary of the sources’ licences, not a contract. We have not yet published customer terms or an API licence. Where this summary and a source’s own terms differ, the source’s terms apply; follow the licence link to read them. Last updated {{ last_updated }}.

{{ m.section_heading("1.", "How to read this") }}
  • Credit is the line the source asks for. Where a source states an exact wording, it is quoted and must be used as written.
  • Statement of changes is required by Creative Commons licences: we have changed the data (mapped fields, normalised values), and anyone passing it on should say so too.
  • Derived fields only means we publish our own normalised fields and change events but not the source’s table; the record links to the source for its rows.
  • Every API response, feed item and export also names its sources and carries their credit lines.
